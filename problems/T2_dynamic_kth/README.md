# T2：动态序列区间第 k 大

## 题目描述

维护一个可以在任意位置插入、删除和修改的整数序列，并回答当前序列指定区间内第 `k` 大的值。插入和删除后，后续元素的下标随之变化。

序列中的每个值均位于 `[-1e9, 1e9]`。初始序列及每次操作后的当前序列均没有重复值；已删除的值可以再次插入。

## 操作约定

所有位置使用从 **0** 开始的下标，区间两端均包含在查询内。测试数据保证操作参数有效。

| 接口 | 含义 |
| --- | --- |
| `DynamicKth(initial)` | 用 `initial` 构造序列，允许初始序列为空 |
| `insert(index, value)` | 在当前 `index` 位置之前插入；`index == 当前长度` 表示末尾追加 |
| `erase(index)` | 删除当前 `index` 位置的元素 |
| `update(index, value)` | 将当前 `index` 位置的元素修改为 `value` |
| `kthLargest(left, right, k)` | 返回当前闭区间 `[left, right]` 中第 `k` 大的值，`k` 从 **1** 开始 |

删除和修改的 `index` 总在当前序列范围内。查询时序列非空，且保证 `0 <= left <= right < 当前长度`、`1 <= k <= right - left + 1`。插入和修改后的序列仍满足值不重复的保证。

例如，初始序列为 `[5, 1, 3]` 时，`kthLargest(0, 2, 2)` 返回 `3`。执行 `insert(1, 4)` 后，序列为 `[5, 4, 1, 3]`；此时 `kthLargest(1, 3, 2)` 返回 `3`。
